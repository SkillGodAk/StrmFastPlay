StrmFastPlay

Jellyfin STRM 起播加速插件

針對 OpenList / AList、PikPak、夸克網盤、迅雷網盤與其他遠端媒體 STRM 場景，改善點擊播放後的等待時間。

主要功能

最佳化 Jellyfin STRM 播放流程，降低遠端媒體的起播等待；支援 OpenList / AList 直鏈與 302 使用情境，並以 PikPak 作為主要實測來源之一；夸克網盤、迅雷網盤等在能透過 OpenList / AList 正常輸出 STRM、直鏈或 302 時也屬於適用場景。

常見問題

Jellyfin STRM 起播很慢，可以改善嗎？

如果延遲主要發生在 Jellyfin 播放 STRM 的準備階段，StrmFastPlay 就是針對這類情境設計。

會提升網盤頻寬嗎？

不會。來源網速、CDN 與網路品質仍由外部服務決定。

核心技術是否公開？

公開文件只說明產品行為、安裝、相容性與支援情境。商業版本的核心最佳化演算法與實作細節不公開。
