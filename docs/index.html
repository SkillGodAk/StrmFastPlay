StrmFastPlay - Jellyfin STRM / 網盤播放加速插件

改善 Jellyfin STRM 起播慢、網盤影片播放前等待時間過長。

GitHub下載

安裝

儲存庫安裝：在 Jellyfin 控制台開啟「插件」→「儲存庫」→「新增」，名稱填入 StrmFastPlay，網址填入 https://skillgodak.github.io/StrmFastPlay/manifest.json，儲存後即可從插件目錄安裝。

手動安裝：從 Releases 下載 ZIP，將 DLL 與 meta.json 解壓到 jellyfin/config/plugins/StrmFastPlay/。兩種方式安裝後都要完整重新啟動 Jellyfin。

Jellyfin 網盤播放很慢怎麼辦？

StrmFastPlay 專門針對 Jellyfin 遠端 STRM / 網盤播放流程進行最佳化，目標是減少點擊播放後可避免的等待時間。
